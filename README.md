# Acerca del proyecto:

[[![Product Name Screen Shot][product-screenshot]](https://pedroglzglz.itch.io/dieselday)

<b>Dieselday</b> es un juego corto de género <i>Survivors-like</i> en el que el jugador debe enfrentarse a oleadas de enemigos infinitos y usar sus múltiples armas
para prevalecer en el campo de batalla.

Este juego fue hecho en <b>Unreal Engine 5</b> para la asignatura <i>Proyecto Grupal III</i> del grado universitario de Diseño y Desarrollo de Videojuegos
por la <i>Universidad Internacional de La Rioja</i> por los siguientes alumnos:

* Juan José Berbel Najas (programación de blueprints y lógica del gameplay, misceláneos)
* Adrián Martínez Villa (artista 3D, concept artist y environmental artist)
* Pedro González González (compositor, diseñador de SFX y programación de blueprints)

En los siguientes apartados se detallarán los pasos seguidos para realizar el proyecto, así como metodologías de trabajo y capturas del <i>framework</i> y código /
softwares utilizados.
